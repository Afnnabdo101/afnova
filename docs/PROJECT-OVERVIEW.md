# فكرة مشروع AFNOVA

## الفكرة

AFNOVA تطبيق Android يهدف إلى إرسال الملفات والمجلدات بين جهازين عبر الإنترنت، حتى لو كانا على شبكتين مختلفتين. الفكرة هي نقل المحتوى مباشرة بين الطرفين متى سمحت الشبكة، بدل الاعتماد على محادثة أو رفع الملف إلى مساحة تخزين سحابية بوصفها المسار الأساسي.

## المشكلة التي يعالجها

إرسال الملفات الكبيرة أو المجلدات الكاملة عبر بعض تطبيقات المحادثة والخدمات السحابية قد يتطلب ضغطًا، حدود حجم، أو رفع الملف ثم تنزيله من جديد. يريد AFNOVA تقديم مسار مباشر وواضح يطلب موافقة المستلم قبل بدء النقل، ويحافظ لاحقًا على ترتيب المجلدات ويدعم استكمال الملفات المنقطعة.

## المسار المستهدف

1. يختار المرسل ملفًا أو مجلدًا.
2. يرسل التطبيق طلبًا إلى الجهاز المستقبِل يتضمن بيانات التعريف اللازمة.
3. يرى المستقبِل اسم المرسل والمحتوى والحجم، ثم يختار القبول أو الرفض.
4. بعد القبول، ينشئ الجهازان جلسة اتصال مباشرة قدر الإمكان عبر الإنترنت.
5. ينقل التطبيق المحتوى ويعرض التقدم، مع استكمال النقل بعد الانقطاع ضمن مرحلة لاحقة.

## ما يعمل اليوم

هذه النسخة **نموذج واجهة أولي**. تعمل الواجهة العربية واتجاه RTL، واختيار عدة ملفات من الجهاز وعرض أسمائها وأحجامها، ومعرض كتيب AFNOVA المصوّر. كما تعرض الواجهة أفكار نقل مستقبلية للتوضيح فقط. لا يوجد اتصال بين جهازين أو طلب قبول حي أو نقل محتوى فعلي حتى الآن.

## حدود النسخة الأولى المستهدفة

- Android إلى Android.
- ملف واحد أولًا، ثم ملفات ومجلدات.
- قبول أو رفض واضح من المستلم قبل النقل.
- نقل مباشر عبر الإنترنت مع مسار مساعد عند تعذر الاتصال المباشر.
- لا يُخزّن خادم الإشارات محتوى الملفات في التصميم المقترح.
