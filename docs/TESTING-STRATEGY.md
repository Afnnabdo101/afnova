# استراتيجية الاختبار

## الفحوص الموجودة

- `dart format --output=none --set-exit-if-changed .` للتأكد من تنسيق Dart.
- `flutter analyze` للتحليل الساكن.
- `flutter test` لاختبارات الواجهة وعارض الدليل.
- GitHub Actions لتشغيل الفحوص عند الدفع إلى `main` وطلبات الدمج.

هذه الفحوص تتحقق من الشيفرة والواجهة فقط؛ لا تختبر نقلًا عبر الإنترنت.

## اختبارات النموذج الحالي

- ظهور علامة AFNOVA والنص العربي.
- وجود صورة الفكرة الرئيسية.
- فتح الدليل المصور والتنقل بين صفحاته.
- عدم إظهار حالة نجاح أو تقدم نقل غير حقيقية.

## اختبارات نقل مطلوبة قبل إطلاق النسخة الأولى

- جهازان حقيقيان على شبكتين مختلفتين، وحالات STUN وTURN.
- الموافقة والرفض والإلغاء وانتهاء مهلة الطلب.
- ملف صغير وصورة وفيديو وملف كبير ومجموعة ملفات.
- انقطاع الشبكة واستئناف النقل والتحقق من تطابق الملف المستلم.
- أسماء ملفات عربية وطويلة ومكررة، مساحة تخزين غير كافية، إغلاق التطبيق وإعادة فتحه.
- قياس الأداء والحرارة واستهلاك البيانات والبطارية، وفحص عدم تسجيل محتوى الملف على الخادم.

تُسجل الاختبارات الفعلية مع الجهاز وإصدار التطبيق ونوع الشبكة والنتيجة؛ لا تُكتب نتيجة مسبقًا.
