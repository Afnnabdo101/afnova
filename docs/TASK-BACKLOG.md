# AFNOVA — قائمة النتائج المطلوبة

## النموذج الأولي — منجز
- [x] تصميم شعار AFNOVA أفقيًا ورمزًا للتطبيق، وتحديث رأس التطبيق وأيقونة Android وREADME.
- [x] واجهة Flutter عربية RTL، توضّح أن النسخة المستهدفة Android ↔ Android وحالة المشروع Prototype.
- [x] اختيار عدة ملفات وعرض أسمائها وأحجامها محليًا.
- [x] عرض المسار المخطط: اختيار الملفات، إرسال الطلب، موافقة المستقبل، ثم النقل؛ مع بيان أنها وظائف مخططة لا شبكة عاملة.
- [x] إضافة بطاقات لميزات الاستكمال الذكي والمجلدات والسرعة والإرسال الجماعي مع وسمها بأنها ضمن خارطة الطريق.
- [x] إضافة معرض داخل التطبيق لصفحات كتيب AFNOVA الأربع، مع التنقل والتكبير.
- [x] إضافة صورة أصلية توضّح نقل الملفات بين هاتفين عبر الإنترنت، وعرضها في التطبيق وREADME.
- [x] إضافة رسومات مفاهيمية للمجلدات والإرسال الجماعي والخصوصية، مع سجل مصادر يوضح أنها ليست ميزات منفذة.
- [x] فصل بطاقات الواجهة ونموذج ميزة خارطة الطريق إلى `lib/widgets/` و`lib/models/`.
- [x] إضافة معرض رسومات مع ظهور متدرج وحركة دخول قصيرة للرسمة الرئيسية.
- [x] توثيق فكرة المشروع والمعمارية وخارطة التطوير والأمان والاختبارات والقرارات والتصميم.
- [x] إضافة مخطط Mermaid لمقترح P2P ومخرجه المرئي.
- [x] تنظيم وثائق خطة المشروع وخارطة التطوير ضمن `docs/`.
- [x] توضيح حدود النسخة وعدم عرض سرعة أو تقدم أو تشفير أو اتصال وهمي.

## المرحلة 1 — أساس الاتصال وإرسال ملف
- [ ] تهيئة اتصال بين جهازي Android عبر الإنترنت، دون اشتراط وجودهما على شبكة Wi‑Fi نفسها.
- [ ] تنفيذ تبادل إشارات الاتصال (Signaling)، وإعداد STUN/TURN أو حل مشابه عند الحاجة لإنشاء الاتصال.
- [ ] إظهار طلب الاستقبال للطرف الآخر متضمنًا اسم المرسل والملف أو المجلد وحجمه.
- [ ] لا يبدأ نقل المحتوى إلا بعد موافقة المستقبل؛ يستطيع المستقبل قبول الطلب أو رفضه.
- [ ] إرسال ملف واحد واستقباله فعليًا بين جهازين عبر الإنترنت.
- [ ] تشفير الاتصال وعدم تخزين الملفات على الخادم في الحالة الطبيعية قدر الإمكان.

## المرحلة 2 — تحسين النقل

- [ ] إرسال مجلد كامل مع الحفاظ على أسماء الملفات وترتيب المجلدات ومساراتها.
- [ ] عرض نسبة تقدم النقل وسرعته الحالية والحجم المنقول والحجم المتبقي.
- [ ] استكمال نقل الملف الكبير من الموضع الذي توقف عنده بعد انقطاع الاتصال بدل البدء من الصفر.
- [ ] تحسين استقرار النقل والتعامل مع انقطاع الإنترنت وإعادة الاتصال.
