# هوية AFNOVA

يرمز الشكل إلى جهازَي هاتف، وبينهما ملف ومسار سهم سريع. العلامة بلا شعارات أنظمة تشغيل أو علامات تجارية خارجية. تعتمد الهوية على الكحلي `#111A2B` والبنفسجي `#8C72FF` والتركواز `#41D9C2`، مع لمسة صفراء في سهم النقل.

| الملف | الاستخدام |
|---|---|
| `afnova-mark.png` | الرمز المربع الشفاف داخل التطبيق. |
| `afnova-mark-wide.png` | نسخة أفقية مقصوصة يستخدمها الشعار المتجهي. |
| `afnova-logo.svg` | شعار أفقي قابل للتعديل، مناسب للخلفيات الفاتحة. |
| `afnova-logo-light.svg` | النسخة الفاتحة للخلفيات الداكنة. |
| `afnova-logo.png` | معاينة أفقية بخلفية بيضاء للـ README والمنصات. |
| `afnova-app-icon.svg` و`afnova-app-icon.png` | مصدر أيقونة Android ومعاينتها. |

حافظ على نسبة الأبعاد والمساحة حول الرمز، ولا تضف كتابة صغيرة داخله. ملفات `mipmap-*` في Android مشتقة من أيقونة التطبيق.
