# هوية AFNOVA

يعرض الرمز ملفًا في الوسط تحيط به حلقتان مفتوحتان متعاكستان؛ إحداهما تركواز والأخرى بنفسجية، مع سهم أصفر وآخر بنفسجي لتوضيح تبادل الملفات. صُممت العلامة لتبقى قابلة للتعرّف عند تصغيرها إلى أيقونة.

| الملف | الاستخدام |
|---|---|
| `afnova-mark.svg` | المصدر المتجهي للرمز المختار. |
| `afnova-mark.png` | الرمز الشفاف المضمّن في واجهة Flutter. |
| `afnova-logo.svg` | الشعار الأفقي القابل للتعديل على خلفية فاتحة. |
| `afnova-logo-light.svg` | نسخة للشاشات والخلفيات الداكنة. |
| `afnova-logo.png` | معاينة PNG للـREADME والمنصات. |
| `afnova-app-icon.svg` و`afnova-app-icon.png` | مصدر ومعاينة أيقونة Android. |

الألوان الأساسية: تركواز `#08B7C8`، بنفسجي `#7139F5`، أصفر `#FFB31A`، وكحلي `#16173A` للأيقونة. حافظ على تناسب الرمز ومساحة تنفسه، ولا تضف عناصر صغيرة داخله. ملفات `mipmap-*` في Android مشتقة من أيقونة التطبيق.
