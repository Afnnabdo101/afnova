# أصول AFNOVA

تُقسم الأصول حسب وظيفتها لتسهيل تحديثها دون خلط العلامة التجارية بالرسوم المفاهيمية أو صفحات الدليل.

- `branding/`: رمز الشعار، النسختان الأفقية، وصورة PNG للـ README وأيقونة Android.
- `guide/`: صفحات الدليل الأربع المستخرجة من كتيب AFNOVA الذي زوّد به صاحب المشروع.
- `illustrations/`: رسوم تصورية مولدة للمشروع، وتُستخدم لشرح الفكرة والميزات في التطبيق وREADME.
- `media-sources.md`: سجل مصدر كل أصل وحالته وملاحظات الاستخدام.

الرسوم المفاهيمية ليست لقطات شاشة ولا توثيقًا على أن الميزات قد نُفذت. عند إضافة أصل جديد، حدّث سجل المصادر، واحفظ نسخة مناسبة للحجم، وتأكد من الإشارة إليه بوضوح في الواجهة.
